공고 이미지 수집 북마클릿 MVP

Jobda와 인디스워크 공고 페이지에서 실행해 공고 이미지/PDF 후보를 수집하고, 자동 다운로드 시도와 manifest 저장을 제공하는 서버 없는 북마클릿입니다.

설치

아래 버튼을 브라우저 북마크바로 드래그하세요.

공고 이미지 수집

북마크바가 보이지 않으면 Chrome 기준 보기 > 북마크바 항상 표시를 켜고 드래그하면 됩니다.

사용법

  1. 지원 사이트의 공고 목록 페이지에 접속합니다.
  2. 북마크바의 공고 이미지 수집을 클릭합니다.
  3. 오버레이에서 후보를 확인하고 필요한 항목만 선택합니다.
  4. 선택 다운로드와 manifest 저장을 실행합니다.

지원 사이트

Jobda: www.jobda.im/position 인디스워크: inthiswork.com/entry Generic fallback

제한사항

브라우저 정책이나 사이트 CORS 때문에 모든 파일이 자동 저장되지는 않을 수 있습니다. 이 경우에도 전체 후보 URL과 실패 정보는 manifest.json에 남깁니다.
